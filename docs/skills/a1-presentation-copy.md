# A1 Presentation Copy

**English** | [Русский](./a1-presentation-copy.ru.md)

Use A1 Presentation Copy to structure one new presentation or write its slide-by-slide message from supplied material.

## The job

The skill builds the shortest coherent message path for a defined audience, occasion, and next step. Each slide has one takeaway, supported evidence, and a useful visual instruction where the material allows one.

## When to use it

Ask for an outline when you need the argument and slide sequence. Ask for a draft when you need takeaway headlines and on-slide copy. State whether the presentation will be delivered live or read independently, because that changes how much meaning must remain on the slides.

The skill does not create a PowerPoint or Google Slides file, design the deck, conduct research, invent data, or edit a selected existing deck.

## What you get

An outline defines the presentation job and ordered slide sequence. A draft gives each slide a takeaway headline, concise on-slide content, and a visual instruction; speaker notes appear only when requested.

> **Try asking:**
>
> `/a1-presentation-copy`
>
> Create a 10-slide live presentation for the COO. Use the attached pilot report and implementation plan. The goal is approval for a six-week rollout. Write takeaway headlines and on-slide copy.

## Common questions

**Does every slide need a headline?**

Yes. The headline states the slide's takeaway rather than merely naming its topic.

**Can it turn a report into slides?**

Yes, when the report is supplied as completed source material. The skill selects and sequences evidence for the presentation's job instead of compressing every section mechanically.

**Will it suggest charts?**

Yes, when the source data supports them. A visual instruction never supplies missing numbers or relationships.

## How to recognize success

- The deck has one audience, occasion, and requested next step.
- The slide order forms a coherent argument rather than a list of topics.
- Each slide carries one takeaway and only the evidence needed for it.
- Numbers retain their units, timeframe, denominator, baseline, and uncertainty.
- On-slide copy remains usable in the stated live or standalone setting.
