# A1 Copy Editing

**English** | [Русский](./a1-copy-editing.ru.md)

Use A1 Copy Editing when you need to make an existing draft clearer, stronger, or easier to act on without changing what its sources support.

## The job

You have a marketing or editorial draft and want a useful edit or an honest review. Select the target by pasting it, attaching it, or explicitly naming the document.

The skill works from the whole text down to paragraphs, sentences, and words. It preserves facts, qualifications, names, numbers, intended meaning, useful voice, and explicit constraints. It does not invent proof, positioning, offers, or strategy to make the copy sound stronger.

## When to use it

Ask in ordinary language to edit, shorten, clarify, strengthen, restructure, apply information-style editing, or review the selected draft. The skill can start automatically when both the draft and editing intent are clear, or through `/a1-copy-editing`.

Use [A1 Humanize](./a1-humanize.md) when the narrow job is to remove recognizable AI-writing patterns. Use a format-specific skill when you need a new article, promo page, press release, or decision memo rather than changes to an existing draft.

## What you get

An editing request returns the edited text and a concise explanation of material changes unless you ask for the text alone. A review request returns prioritized findings and recommendations without silently rewriting the draft. A compatible combined request returns the edit first, then only the findings and next steps that remain useful.

Marketing Context is optional. When available and allowed, it supplies confirmed defaults and protected inputs. Missing optional context does not block a safe, useful edit.

## Common questions

**Do I need to describe the audience, channel, and tone first?**

No. The skill asks only when every safe edit would force a choice between materially different meanings.

**Can I ask for feedback without a rewrite?**

Yes. Ask for a review and say that you do not want the text rewritten.

**Does “make it more persuasive” allow stronger claims?**

No. The skill can foreground existing value and proof, but it cannot remove uncertainty or add evidence absent from the sources.

**Can it create a campaign or positioning from scratch?**

No. Every deliverable must edit or review the selected draft.

## How to recognize success

- The result is observably clearer, tighter, better structured, or more correct.
- The useful point appears early enough for the intended reading mode.
- Facts, qualifications, names, numbers, and protected inputs survive the edit.
- Necessary examples, mechanisms, trade-offs, and limits are not cut for brevity.
- A review-only request produces prioritized feedback without an unsolicited rewrite.
