# Marketing Skills

[English](./README.md) | **Русский**

Marketing Skills помогает маркетологам, предпринимателям и авторам работать с ИИ-агентами обычными словами. Набор умеет сохранять сведения о продукте, улучшать готовые тексты, ставить сложные редакторские задачи и обновлять себя, не затрагивая посторонние навыки.

## Быстрый старт

1. Убедитесь, что установлен [Node.js](https://nodejs.org/en/download). Выберите актуальную LTS-версию: вместе с ней установятся `npm` и `npx`.
2. Откройте терминал в любой папке и установите Marketing Skills глобально:

   ```bash
   npx skills@latest add ztemerbekov/marketing-skills -g
   ```

3. Выберите нужные навыки и ИИ-клиенты. Рекомендуем установить все четыре навыка. Если установщик спросит о способе установки, выберите **Symlink**.
4. Откройте или перезагрузите ИИ-клиент, а затем опишите задачу обычными словами:

   ```text
   Сократи этот текст, сохрани факты и спокойный тон:

   [ваш текст]
   ```

После глобальной установки навыки доступны во всех проектах. В разделе [«Установка»](#установка) есть дополнительный вариант только для одного проекта.

Простое правило выбора:

- Хотите, чтобы агент запомнил продукт, аудиторию, стиль общения или подтверждения для следующих задач? Начните с **Маркетингового контекста**.
- У вас уже есть текст и вы знаете, что нужно изменить? Используйте **Редактор**.
- Сначала нужно определить читателя, цель, формат, ограничения, позиционирование или сообщение? Явно запустите **Шеф-редактор**.
- Хотите получить свежую версию этого набора и не обновлять посторонние навыки? Попросите **Обновление Marketing Skills**.

Маркетинговый контекст полезен для регулярной работы, но Редактор может улучшить присланный текст и без него.

## Познакомьтесь с навыками

<details>
<summary><strong>Маркетинговый контекст</strong></summary>

**Что делает:** сохраняет в текущем проекте сведения о продукте, аудитории, позиционировании, стиле общения, подтверждениях, словаре, примерах и бизнес-целях. Другие маркетинговые навыки смогут использовать эти сведения в следующих задачах.

**Когда использовать:** в начале маркетинговой работы над проектом, а также после изменения продукта, аудитории, подтверждений, терминологии или правил стиля.

**Пример запроса:**

```text
Сохрани сведения о нашем продукте, аудитории, позиционировании, стиле общения, подтверждениях, предпочтительных словах и бизнес-целях для следующих маркетинговых задач.
```

</details>

<details>
<summary><strong>Редактор</strong></summary>

**Что делает:** улучшает готовый текст. Редактор может отредактировать, сократить, прояснить, усилить или перестроить материал, сохранив подтверждённые факты, важные оговорки и полезные особенности авторского голоса. Если вы приложили текст и описали нужное изменение, работа начнётся сразу.

**Когда использовать:** основное маркетинговое решение уже принято, а существующий текст нужно сделать яснее, короче или логичнее.

**Пример запроса:**

```text
Сделай этот блок лендинга понятнее и короче. Сохрани все числа и не добавляй новых обещаний:

[ваш текст]
```

Если нужен информационный стиль, назовите его прямо: «Отредактируй в информационном стиле» или «по Ильяхову». Обычная просьба «почисти текст» включает более бережную стандартную редактуру.

Создание или пересмотр позиционирования, оффера, аудитории, сообщений кампании или структуры лендинга находится за границей текстовой редактуры. Редактор рекомендует явно запустить `a1-editor-in-chief`; он не начинает интервью шеф-редактора автоматически.

</details>

<details>
<summary><strong>Шеф-редактор</strong></summary>

**Что делает:** помогает поставить стратегическую или сложную редакторскую задачу до начала переписывания. Он задаёт только вопросы, без которых нельзя продолжить, составляет редакторский бриф и передаёт выбранную операцию Редактору.

**Когда использовать:** читателя, цель, формат, ограничения, позиционирование, сообщение или тип редактуры ещё нужно определить. Этот навык запускается только по явной просьбе.

**Пример запроса:**

```text
Запусти a1-editor-in-chief. Помоги определить аудиторию, цель, сообщение и ограничения для этой страницы, а затем отредактируй приложенный текст.
```

</details>

<details>
<summary><strong>Обновление Marketing Skills</strong></summary>

**Что делает:** обновляет только навыки, установленные из этого репозитория. Он заменяет существующие версии во всех уже подключённых клиентах, удаляет навыки, исчезнувшие из `main`, и показывает новые доступные навыки перед установкой.

**Когда использовать:** нужна свежая версия Marketing Skills, но нельзя обновлять другие наборы. Установленные файлы заменяются опубликованной версией вместе с ручными изменениями внутри этих файлов.

**Пример запроса:**

```text
Обнови Marketing Skills.
```

</details>

<details>
<summary>📁 <strong>Установка только в текущий проект</strong></summary>

Откройте терминал в проекте и уберите `-g`:

```bash
npx skills@latest add ztemerbekov/marketing-skills
```

Этот вариант нужен, когда проект должен хранить собственные версии навыков. В остальных случаях выбирайте глобальную установку.

</details>

<details>
<summary>🗑️ <strong>Удаление Marketing Skills</strong></summary>

Удалить текущий глобальный набор из всех подключённых клиентов:

```bash
npx skills@latest remove \
  a1-setup-marketing-context \
  a1-editor \
  a1-editor-in-chief \
  a1-update-marketing-skills \
  --global \
  --yes
```

Для установки только в проекте выполните команду в этом проекте и уберите `--global`.

</details>

## Обновление

Рекомендуемый способ обновления — разговорный. Попросите ИИ-агента:

```text
Обнови Marketing Skills.
```

После этого `a1-update-marketing-skills`:

- обновит существующие Marketing Skills из актуального `main` во всех уже подключённых клиентах;
- также обновит установку в проекте, если она есть в текущей папке;
- перезапишет ручные изменения внутри установленных файлов без резервной копии;
- без вопроса удалит навыки, удалённые или переименованные в репозитории;
- покажет новые навыки одним списком и спросит, установить все или только выбранные;
- не затронет навыки из других репозиториев.

Если вы отказались от нового навыка, он снова появится при следующем обновлении. Обновляющий навык не ищет другие проекты на компьютере и не подключает новый ИИ-клиент без разрешения.

Если удобнее пользоваться терминалом, повторите команду установки из этого репозитория и выберите навыки и клиенты для обновления:

```bash
npx skills@latest add ztemerbekov/marketing-skills -g
```

Разговорный способ предпочтительнее, если нужна полная проверка источника, автоматическая очистка и просмотр новых навыков.

## Как пользоваться

- Пишите на привычном языке. По умолчанию навыки отвечают на нём и сохраняют язык исходного текста.
- Передавайте Редактору полный текст и понятную задачу: «сократи», «проясни», «усиль» или «перестрой».
- Сразу называйте важные ограничения: сохранить числа, голос, структуру или вернуть только готовый текст.
- Настройте Маркетинговый контекст, если хотите использовать одни и те же сведения о продукте и стиле общения в регулярных задачах. Без контекста обычная редактура всё равно работает.
- Назовите Шеф-редактор явно, если хотите сначала уточнить задачу, а затем редактировать.
- Попросите Обновление Marketing Skills, когда нужно освежить только этот набор.
