**Отдаем рутину AI-агентам, чтобы освободить фокус команды для стратегии, смыслов и решений, которые двигают бизнес.**

A1 Marketing Skills — это набор навыков для ИИ-агентов, созданный для всей маркетинговой команды. Набор чётко разделяет исполнение и принятие решений: агенты забирают повторяющуюся операционку и рутину, а маркетологи сохраняют экспертный контроль, ясный фокус и управление решениями о росте.

---

## Что уже умеют агенты

Набор разделён на два взаимосвязанных пакета для работы с маркетинговыми решениями, общим контекстом, психологией потребителя и текстом.

### A1 Core — Экспертиза и решения

1. **[Прожарка](./docs/skills/a1-grill.ru.md)** (`/a1-grill`) проверяет на прочность маркетинговую идею, решение или план через интервью раундами.
2. **[Психология потребителя](./docs/skills/a1-consumer-psy.ru.md)** (`/a1-consumer-psy`) проверяет гипотезы психологии потребителя перед запуском и объясняет фактические результаты тестов по научной базе, отсеивая псевдонаучные мифы.
3. **[Маркетинговый контекст](./docs/skills/a1-marketing-context.ru.md)** (`/a1-marketing-context`) фиксирует подтверждённый маркетинговый контекст команды в `.agents/marketing-context.md`, чтобы навыки, работающие с контекстом, использовали реальные вводные, а не додумывали их.

### A1 Editorial — Редактура и тексты

4. **[A1 Copy Editing](./docs/skills/a1-copy-editing.ru.md)** (`/a1-copy-editing`, русский алиас [`/a1-redaktura`](./docs/skills/a1-redaktura.ru.md)) редактирует или разбирает готовые черновики внутри переданных ограничений и доступного Маркетингового контекста, сохраняя факты исходника и контроль человека над финальными решениями.
5. **[Оживить текст](./docs/skills/a1-humanize.ru.md)** (`/a1-humanize`) убирает узнаваемые AI-паттерны, сохраняя естественный ритм, голос и фактуру автора.

## Главные принципы работы

- **Единый маркетинговый контекст.** Сохранённые и подтверждённые вводные команды хранятся в `.agents/marketing-context.md`, чтобы процессы, работающие с контекстом, опирались на единый источник, а не выдуманные данные.
- **Верность источнику.** Редакционные навыки сохраняют факты, цифры, термины, оговорки и авторский смысл, не добавляя недостающие утверждения, доказательства или стратегию.

## Увидеть работу за минуту

Полный цикл от контекста до редактуры выглядит так:

> **Вы:** Проанализируй файлы в папке проекта X и собери из них базовый маркетинговый контекст.
>
> **Результат:** Агент вытаскивает позиционирование, ЦА и правила бренда и фиксирует их в `.agents/marketing-context.md`, чтобы совместимые навыки, работающие с контекстом, могли использовать эти вводные без повторных вопросов.
>
> **Вы:** Сделай текст яснее и короче, затем убери заметные AI-штампы:
>
> `[вставьте черновик]`
>
> **Результат:** Готовый чистый текст в Tone of Voice бренда: без воды и AI-штампов, с сохранённым смыслом.

## Быстрый старт

Самый короткий путь к полезному результату — глобальная установка и первый запрос к A1 Copy Editing.

1. Откройте терминал и установите набор. Одна и та же однострочная команда работает в Bash, Command Prompt и PowerShell:

   ```bash
   npx skills@latest add ztemerbekov/a1-marketing-skills -g
   ```

2. Когда установщик спросит, выберите ИИ-агентов, которыми уже пользуетесь, и отметьте `a1-copy-editing` или другие нужные навыки. Для явной русской команды отметьте и `a1-copy-editing`, и его алиас `a1-redaktura`.

3. Откройте проект с черновиком в выбранном агенте. A1 Copy Editing может запуститься по обычному запросу:

   > Сделай этот абзац понятнее и короче. Сохрани каждый факт и не добавляй новых утверждений.
   >
   > Верни только отредактированный текст:
   >
   > `[вставьте черновик]`

4. Для регулярной работы в одном репозитории добавьте общий контекст:

   > Настрой маркетинговый контекст по подтверждённой информации в этом репозитории.

   Этот явный запрос создаёт или обновляет `.agents/marketing-context.md`. Сама установка никогда не создаёт этот файл.

## Другие способы установки

### Marketplace Codex

Один раз добавьте marketplace репозитория:

```bash
codex plugin marketplace add ztemerbekov/a1-marketing-skills
codex plugin add a1-marketing-skills@a1-marketing-skills
```

После установки начните новую сессию, чтобы Codex загрузил навыки плагина. Marketplace репозитория и сам плагин также можно открыть и управлять ими через `/plugins`.

### Marketplace Cursor

Один раз добавьте marketplace репозитория:

```bash
cursor-agent plugin marketplace add https://github.com/ztemerbekov/a1-marketing-skills
```

Запустите `cursor-agent`, откройте `/plugin`, выберите marketplace **A1 Marketing Skills** и установите плагин **A1 Marketing Skills** на уровне пользователя или проекта.

### Marketplace Claude Code

Один раз добавьте marketplace:

```text
/plugin marketplace add ztemerbekov/a1-marketing-skills
```

Для полной установки A1 Marketing Skills:

```text
/plugin install a1-marketing-skills@a1-marketing-skills
```

В полную установку входят оба набора:

- **A1 Core:** `/a1-core:a1-grill`, `/a1-core:a1-consumer-psy` и `/a1-core:a1-marketing-context`
- **A1 Editorial:** `/a1-editorial:a1-copy-editing`, его русский алиас `/a1-editorial:a1-redaktura` и `/a1-editorial:a1-humanize`

Чтобы установить только один набор:

```text
/plugin install a1-core@a1-marketing-skills
/plugin install a1-editorial@a1-marketing-skills
```

### Только один проект

Выполните основную команду внутри проекта и уберите `-g`:

```bash
npx skills@latest add ztemerbekov/a1-marketing-skills
```

При проектной установке выбранные версии навыков остаются с этим проектом. Полный актуальный список агентов и поведение установщика описаны в документации [`skills`](https://github.com/vercel-labs/skills).

## Обновление и удаление

Обновите пять возможностей и русский командный алиас:

```bash
npx skills@latest update a1-copy-editing a1-redaktura a1-grill a1-humanize a1-marketing-context a1-consumer-psy --global --yes
```

Удалите их из глобальной установки:

```bash
npx skills@latest remove a1-copy-editing a1-redaktura a1-grill a1-humanize a1-marketing-context a1-consumer-psy --global --yes
```

Для проектных навыков выполните команду внутри проекта: используйте `--project` с `update` и уберите `--global` из `remove`.
