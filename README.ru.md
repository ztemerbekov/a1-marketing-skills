**Отдаем рутину AI-агентам, чтобы освободить фокус команды для стратегии, смыслов и решений, которые двигают бизнес.**

A1 Marketing Skills — это набор навыков для ИИ-агентов, созданный для всей маркетинговой команды. Набор чётко разделяет исполнение и принятие решений: агенты забирают повторяющуюся операционку и рутину, а маркетологи сохраняют экспертный контроль, ясный фокус и управление решениями о росте.

---

## 5 навыков системы

Набор разделён на два взаимосвязанных пакета для работы с маркетинговым контекстом, решениями и текстом.

### A1 Core — Контекст и решения

1. **Маркетинговый контекст** (`/a1-marketing-context`) фиксирует подтверждённый маркетинговый контекст команды в `.agents/marketing-context.md`, чтобы навыки, работающие с контекстом, использовали реальные вводные, а не додумывали их.
2. **Прожарка** (`/a1-grill`) проверяет на прочность маркетинговую идею, решение или план через конструктивное интервью.

### A1 Editorial — Редактура и тексты

3. **Редактор** (`/a1-editor`) улучшает готовые черновики внутри переданных ограничений и доступного Маркетингового контекста, сохраняя факты исходника.
4. **Шеф-редактор** (`/a1-editor-in-chief`) задаёт редакционное направление внутри утверждённой стратегии, ставит задачу Редактору и проверяет итоговую редактуру.
5. **Оживить текст** (`/a1-humanize`) убирает узнаваемые AI-паттерны, сохраняя естественный ритм, голос и фактуру автора.

## Главные принципы работы

- **Единый маркетинговый контекст.** Сохранённые и подтверждённые вводные команды хранятся в `.agents/marketing-context.md`, чтобы процессы, работающие с контекстом, опирались на единый источник, а не выдуманные данные.
- **Верность источнику.** Редакционные навыки сохраняют факты, цифры, термины, оговорки и авторский смысл, не добавляя недостающие утверждения, доказательства или стратегию.

```text
    [вставьте черновик]
Результат: Переработанный текст и короткое описание изменений.
```

## Быстрый старт

Самый короткий путь к полезному результату — глобальная установка и первый запрос Редактору.

1. Откройте терминал и установите набор:

   ```bash
   npx skills@latest add ztemerbekov/a1-marketing-skills -g
   ```

2. Когда установщик спросит, выберите ИИ-агентов, которыми уже пользуетесь, и отметьте `a1-editor` или другие нужные навыки.

3. Откройте проект с черновиком в выбранном агенте. Редактор может запуститься по обычному запросу:

   ```text
   Сделай этот абзац понятнее и короче. Сохрани каждый факт и не добавляй новых утверждений.
   Верни только отредактированный текст:

   [вставьте черновик]
   ```

4. Для регулярной работы в одном репозитории добавьте общий контекст:

   ```text
   Настрой маркетинговый контекст по подтверждённой информации в этом репозитории.
   ```

   Этот явный запрос создаёт или обновляет `.agents/marketing-context.md`. Сама установка никогда не создаёт этот файл.

## Подробнее о навыках

<details>
<summary><strong>Маркетинговый контекст — сохраняет подтверждённую информацию для следующих задач</strong></summary>

Маркетинговый контекст создаёт или пошагово обновляет один файл `.agents/marketing-context.md` в текущем репозитории. Он записывает подтверждённые пользователем сведения и факты из авторитетных материалов проекта, но никогда не создаёт и не оценивает гипотезы.

Обычный запрос на сохранение или обновление запускает Auto-draft. Интервью начинается только по явной просьбе: навык задаёт по одному вопросу, сохраняет подтверждённый прогресс после каждого ответа и останавливается не позднее седьмого вопроса за один проход.

**Попробуйте:**

```text
Добавь в маркетинговый контекст целевую аудиторию: руководители операционных команд маркетплейсов.

Запомни наш tone of voice: практично, спокойно и прямо.

Зафиксируй редакционную политику из подтверждённых материалов этого репозитория.

Запомни ограничения и запреты: [перечислите стоп-слова, брендовые ограничения и темы-табу].
```

Полное поведение описано в [инструкции Маркетингового контекста](./skills/a1-marketing-context/SKILL.md).

</details>

<details>
<summary><strong>Прожарка — проверяет решение на прочность до исполнения</strong></summary>

Прожарка проводит конструктивно требовательное интервью об одной маркетинговой идее, решении или плане. Каждый ход начинается с одной рекомендации и заканчивается одним вопросом. Навык следует зависимостям реального решения, а не фиксированному списку тем.

После подтверждения общего понимания Прожарка возвращает решение, ключевые причины, оставшиеся допущения или отложенные ветки и один рекомендуемый следующий шаг. Она не исполняет план, не создаёт маркетинговые материалы и не проводит полное исследование рынка.

**Попробуйте:**

```text
Запусти a1-grill. Прожарь эту идею по одному решению за раз:
создать Telegram-канал для получения квалифицированных лидов
на сервис аналитики маркетплейсов.
```

Полное поведение описано в [инструкции Прожарки](./skills/a1-grill/SKILL.md).

</details>

<details>
<summary><strong>Редактор — улучшает готовый текст, не выдумывая фактов</strong></summary>

Редактор запускается, когда вы присылаете текст и формулируете редакторскую задачу. Он может сократить, прояснить, усилить или перестроить текст, исправить язык или применить информационный стиль, сохраняя прослеживаемые факты, утверждения, оговорки, числа и полезные особенности голоса.

Отсутствие аудитории, канала, цели или Маркетингового контекста не мешает безопасной редактуре. Запросы на создание позиционирования, оффера, аудитории, сообщения кампании или другого стратегического решения останавливаются на границе навыка.

**Попробуйте:**

```text
Сделай по Ильяхову:

[вставьте черновик]
```

Полное поведение описано в [инструкции Редактора](./skills/a1-editor/SKILL.md).

</details>

<details>
<summary><strong>Оживить текст — убирает AI-паттерны, не стирая голос автора</strong></summary>

Навык работает только с готовым текстом, переданным в разговоре. Он распознаёт паттерны по их функции на разных языках, сохраняет подтверждённое содержание и значимые авторские особенности, не добавляет утверждений, мнений, историй, офферов или CTA.

Навык никогда не читает и не перезаписывает файлы проекта. Если один запрос объединяет очеловечивание текста с созданием новой маркетинговой стратегии, работа останавливается до частичной переработки.

**Попробуйте:**

```text
Очеловечь этот абзац. Сохрани каждый факт
и верни только итоговую версию:

[вставьте текст]
```

Полное поведение описано в [инструкции Оживить текст](./skills/a1-humanize/SKILL.md).

</details>

<details>
<summary><strong>Шеф-редактор — направляет и проверяет ответственную редактуру</strong></summary>

Шеф-редактор работает внутри подтверждённых продуктовых и маркетинговых решений. Он разрешает источники, выбирает ограниченное редакционное направление, создаёт внутренний бриф, передаёт всю работу с текстом Редактору и проверяет результат не более чем с одним корректирующим проходом.

Используйте его, когда утверждённая стратегия уже есть, но фокус на читателе, акцент сообщения, редакционный угол, порядок аргументов, структура или голос ещё требуют решения шеф-редактора. Навык не создаёт позиционирование, сегментацию, цену, оффер, стратегию кампании, GTM или продуктовую стратегию.

**Попробуйте:**

```text
Запусти a1-editor-in-chief. Аудитория и позиционирование ниже уже утверждены.
Выбери сильнейший редакционный угол и порядок аргументов для письма,
передай переписывание Редактору и проверь результат.

Утверждённая стратегия: [аудитория и позиционирование]
Исходный текст: [вставьте текст]
```

Полное поведение описано в [инструкции Шеф-редактора](./skills/a1-editor-in-chief/SKILL.md).

</details>

## Другие способы установки

### Marketplace Claude Code

Один раз добавьте marketplace:

```text
/plugin marketplace add ztemerbekov/a1-marketing-skills
```

Установите полный набор:

```text
/plugin install a1-marketing-suite@a1-marketing-skills
```

A1 Marketing Suite устанавливает оба функциональных набора как зависимости и не содержит собственных навыков или команд:

- **A1 Core:** `/a1-core:a1-marketing-context` и `/a1-core:a1-grill`
- **A1 Editorial:** `/a1-editorial:a1-editor`, `/a1-editorial:a1-humanize` и `/a1-editorial:a1-editor-in-chief`

Чтобы установить только один набор:

```text
/plugin install a1-core@a1-marketing-skills
/plugin install a1-editorial@a1-marketing-skills
```

### Только один проект

Выполните основную команду внутри проекта и уберите `-g`:

```bash
npx skills@latest add ztemerbekov/a1-marketing-skills
```

При проектной установке выбранные версии навыков остаются с этим проектом. Полный актуальный список агентов и поведение установщика описаны в документации [`skills`](https://github.com/vercel-labs/skills).

## Обновление и удаление

Обновите пять глобально установленных навыков:

```bash
npx skills@latest update \
  a1-editor \
  a1-editor-in-chief \
  a1-grill \
  a1-humanize \
  a1-marketing-context \
  --global \
  --yes
```

Удалите их из глобальной установки:

```bash
npx skills@latest remove \
  a1-editor \
  a1-editor-in-chief \
  a1-grill \
  a1-humanize \
  a1-marketing-context \
  --global \
  --yes
```

Для проектных навыков выполните команду внутри проекта: используйте `--project` с `update` и уберите `--global` из `remove`.
