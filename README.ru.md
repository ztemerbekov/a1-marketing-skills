**Отдаем рутину AI-агентам, чтобы освободить фокус команды для стратегии, смыслов и решений, которые двигают бизнес.**

A1 Marketing Skills — это набор навыков для ИИ-агентов, созданный для всей маркетинговой команды. Набор чётко разделяет исполнение и принятие решений: агенты забирают повторяющуюся операционку и рутину, а маркетологи сохраняют экспертный контроль, ясный фокус и управление решениями о росте.

---

## Что уже умеют агенты

Набор разделён на два взаимосвязанных пакета для работы с маркетинговыми решениями, общим контекстом, психологией потребителя и текстом.

### A1 Core — Экспертиза и решения

1. **Прожарка** (`/a1-grill`) проверяет на прочность маркетинговую идею, решение или план через конструктивное интервью.
2. **Психология потребителя** (`/a1-consumer-psy`) проверяет гипотезы психологии потребителя перед запуском и объясняет фактические результаты тестов по научной базе, отсеивая псевдонаучные мифы.
3. **Маркетинговый контекст** (`/a1-marketing-context`) фиксирует подтверждённый маркетинговый контекст команды в `.agents/marketing-context.md`, чтобы навыки, работающие с контекстом, использовали реальные вводные, а не додумывали их.

### A1 Editorial — Редактура и тексты

4. **A1 Copy Editing** (`/a1-copy-editing`, русский алиас `/a1-redaktura`) редактирует или разбирает готовые черновики внутри переданных ограничений и доступного Маркетингового контекста, сохраняя факты исходника и контроль человека над финальными решениями.
5. **Шеф-редактор** (`/a1-editor-in-chief`) задаёт редакционное направление внутри утверждённой стратегии, ставит задачу A1 Copy Editing и проверяет итоговую редактуру.
6. **Оживить текст** (`/a1-humanize`) убирает узнаваемые AI-паттерны, сохраняя естественный ритм, голос и фактуру автора.

## Главные принципы работы

- **Единый маркетинговый контекст.** Сохранённые и подтверждённые вводные команды хранятся в `.agents/marketing-context.md`, чтобы процессы, работающие с контекстом, опирались на единый источник, а не выдуманные данные.
- **Верность источнику.** Редакционные навыки сохраняют факты, цифры, термины, оговорки и авторский смысл, не добавляя недостающие утверждения, доказательства или стратегию.

## Увидеть работу за минуту

Полный цикл от контекста до редактуры выглядит так:

> **Вы:** Проанализируй файлы в папке проекта X и собери из них базовый маркетинговый контекст.
>
> **Результат:** Агент вытаскивает позиционирование, ЦА и правила бренда и фиксирует их в `.agents/marketing-context.md` — чтобы последующие вызовы всех навыков автоматически учитывали контекст и вам не приходилось передавать вводные заново.
>
> **Вы:** Сделай по Ильяхову и перепиши так, будто писал человек, а то прямо видно, что нейронка писала:
>
> `[вставьте черновик]`
>
> **Результат:** Готовый чистый текст в Tone of Voice бренда без воды и AI-штампов, переработанный по канонам книги «Пиши, сокращай».

## Быстрый старт

Самый короткий путь к полезному результату — глобальная установка и первый запрос к A1 Copy Editing.

1. Откройте терминал и установите набор:

   ```bash
   npx skills@latest add ztemerbekov/a1-marketing-skills -g
   ```

2. Когда установщик спросит, выберите ИИ-агентов, которыми уже пользуетесь, и отметьте `a1-copy-editing` или другие нужные навыки. Для явной русской команды отметьте и `a1-copy-editing`, и его алиас `a1-redaktura`.

3. Откройте проект с черновиком в выбранном агенте. A1 Copy Editing может запуститься по обычному запросу:

   > Сделай этот абзац понятнее и короче. Сохрани каждый факт и не добавляй новых утверждений.
   >
   > Верни только отредактированный текст:
   >
   > `[вставьте черновик]`

4. Для регулярной работы в одном репозитории добавьте общий контекст:

   > Настрой маркетинговый контекст по подтверждённой информации в этом репозитории.

   Этот явный запрос создаёт или обновляет `.agents/marketing-context.md`. Сама установка никогда не создаёт этот файл.

## Подробнее о навыках

<details>
<summary><strong>Маркетинговый контекст — сохраняет подтверждённую информацию для следующих задач</strong></summary>

<br>

Маркетинговый контекст создает или пошагово обновляет файл `.agents/marketing-context.md` — единый источник подтвержденных вводных о вашем бренде для следующих задач.

Запустить обновление можно двумя способами:

- **Обычный запрос или команда:** навык собирает подтвержденные факты из переданных документов и формирует контекст.
- **Пошаговое интервью:** если данных в файлах не хватает, попросите навык задать вопросы. Он начинает короткий диалог, задает по одному вопросу и сохраняет подтвержденный прогресс после каждого ответа.

**Попробуйте:**

Контекст можно пополнять целиком или отдельными подтверждёнными блоками — достаточно указать, что сохранить и из какого источника.

> Проанализируй файлы во вложении и зафиксируй в контексте наш Brand Voice, Customer Profiles, редполитику, брендовые ограничения и список стоп-слов.
>
> Зафиксируй в контексте портреты ЦА, сегменты, ICP (Ideal Customer Profile) и ключевые боли B2B-покупателей из презентации.
>
> Добавь в контекст позиционирование бренда, UVP (ценностное предложение), миссию и ключевые смыслы из файла.
>
> Собери в контексте наш Tone of Voice, характер коммуникации, принципы верстки и примеры проявления голоса бренда.
>
> Запиши в контекст редакционную политику, правила форматирования, требования к структуре и правила оформления численных фактов.
>
> Сохрани в контексте брендовые запреты, юридические табу, список стоп-слов и правила упоминания продуктов-конкурентов.
>
> Зафиксируй ключевые продукты, их фичи, переложенные на язык пользы, и главные офферы для текущей кампании.

Полное поведение описано в [инструкции Маркетингового контекста](./skills/a1-marketing-context/SKILL.md).

</details>

<details>
<summary><strong>Прожарка — проверяет решение на прочность до исполнения</strong></summary>

<br>

Прожарка — жесткий, но конструктивный разбор маркетинговой идеи или плана. Без сюсюканья и воды, но без токсичности и пассивной агрессии, как от коллег.

Каждый шаг — одна четкая рекомендация и один точный вопрос. Навык глубоко анализирует решение, а не идет по чек-листу.

Что на выходе: Прожарка выдаст готовое решение, вскроет риски с допущениями и даст конкретный следующий шаг.

**Попробуйте:**

> `/a1-grill`
>
> Есть идея запустить Telegram-канал для привлечения B2B-лидов на наш сервис. Помоги раскидать гипотезу и подсвети, где у нас слабые места и слепые зоны.

Полное поведение описано в [инструкции Прожарки](./skills/a1-grill/SKILL.md).

</details>

<details>
<summary><strong>A1 Copy Editing — редактирует или разбирает готовый текст, не выдумывая фактов</strong></summary>

<br>

Используйте **A1 Copy Editing**, когда нужно причесать готовый текст или получить редакторский разбор до внесения изменений. Навык сокращает «воду», проясняет смысл, убирает канцелярит, применяет инфостиль по явной просьбе или даёт фидбек без скрытой переписи. Факты, цифры и авторский голос остаются на месте, а финальные редакторские решения — за человеком.

Ему не обязательно разжевывать ЦА, канал или цель — он качественно отредактирует текст и так.

*Ограничения:* A1 Copy Editing работает только с готовым текстом. Если вам нужно с нуля придумать позиционирование, оффер или стратегию кампании — это задача для других навыков.

Русскоязычные пользователи могут явно вызвать то же поведение командой `/a1-redaktura`. Это алиас, а не отдельный редакторский навык; рядом с ним должен быть установлен `a1-copy-editing`.

**Попробуйте:**

> `/a1-copy-editing`
>
> Сделай по Ильяхову, уложись в три абзаца:
>
> `[вставьте черновик]`

Для русской команды замените `/a1-copy-editing` на `/a1-redaktura`.

Или запросите разбор без автоматической переписи:

> Дай фидбек на текст и разбери мой текст. Пока не переписывай:
>
> `[вставьте черновик]`

Полное поведение описано в [инструкции A1 Copy Editing](./skills/a1-copy-editing/SKILL.md).

</details>

<details>
<summary><strong>Оживить текст — убирает AI-паттерны, не стирая голос автора</strong></summary>

<br>

Навык работает только с готовым текстом, переданным в разговоре. Он распознаёт паттерны по их функции на разных языках, сохраняет подтверждённое содержание и значимые авторские особенности, не добавляет утверждений, мнений, историй, офферов или CTA.

Навык никогда не читает и не перезаписывает файлы проекта. Если один запрос объединяет очеловечивание текста с созданием новой маркетинговой стратегии, работа останавливается до частичной переработки.

**Попробуйте:**

> `/a1-humanize`
>
> Оживи текст, сбей этот нейросетевой ритм:
>
> `[вставьте текст]`

Полное поведение описано в [инструкции Оживить текст](./skills/a1-humanize/SKILL.md).

</details>

<details>
<summary><strong>Шеф-редактор — направляет и проверяет ответственную редактуру</strong></summary>

<br>

Шеф-редактор работает внутри подтверждённых продуктовых и маркетинговых решений. Он разрешает источники, выбирает ограниченное редакционное направление, создаёт внутренний бриф, передаёт всю работу с текстом в A1 Copy Editing и проверяет результат не более чем с одним корректирующим проходом.

Используйте его, когда утверждённая стратегия уже есть, но фокус на читателе, акцент сообщения, редакционный угол, порядок аргументов, структура или голос ещё требуют решения шеф-редактора. Навык не создаёт позиционирование, сегментацию, цену, оффер, стратегию кампании, GTM или продуктовую стратегию.

**Попробуйте:**

> `/a1-editor-in-chief`
>
> Посмотри черновик. Найди самый сильный угол подачи для директоров по маркетингу и перепиши текст под эту задачу.
>
> `[вставьте черновик]`

Полное поведение описано в [инструкции Шеф-редактора](./skills/a1-editor-in-chief/SKILL.md).

</details>

<details>
<summary><strong>Психология потребителя — проверяет гипотезы по научной базе</strong></summary>

<br>

**Что делает:** проверяет гипотезы психологии потребителя перед запуском и объясняет фактические результаты тестов по научной базе, отсеивая псевдонаучные мифы.

**Когда использовать:** когда вы явно вызываете `a1-consumer-psy`, чтобы проверить гипотезу психологии потребителя перед запуском или объяснить результат маркетингового теста. Навык опирается только на текущий запрос и прямо переданные готовые материалы; он не расследует трафик, аналитику, атрибуцию, технические сбои или другие психологические механизмы.

**Пример запроса:**

> `/a1-consumer-psy`
>
> Разбери падение конверсии выбора тарифа после изменения страницы. Дай только доказательно ограниченные гипотезы и фальсифицируемый тест.

Навык покрывает семейства моделей, описанные в его локальных references. Он даёт анализ, гипотезы, эксперименты, метрики, countermetrics и предупреждения о рисках исполнения; он не создаёт копирайтинг, страницы, тарифы, кампании или production-реализацию. Если вмешательство обманчиво или несёт риск, навык предупредит об этом и предложит прозрачную альтернативу для теста.

Широкие фреймворки и ошибки аналитика здесь работают как guardrails: они направляют разбор или объясняются отдельно, но не выдаются за основную психологическую причину пользователя.

</details>

## Другие способы установки

### Marketplace Codex

Один раз добавьте marketplace репозитория:

```bash
codex plugin marketplace add ztemerbekov/a1-marketing-skills
codex plugin add a1-marketing-suite@a1-marketing-skills
```

После установки начните новую сессию, чтобы Codex загрузил навыки плагина. Marketplace репозитория и сам плагин также можно открыть и управлять ими через `/plugins`.

### Marketplace Cursor

Один раз добавьте marketplace репозитория:

```bash
cursor-agent plugin marketplace add https://github.com/ztemerbekov/a1-marketing-skills
```

Запустите `cursor-agent`, откройте `/plugin`, выберите marketplace **A1 Marketing Skills** и установите плагин **A1 Marketing Skills** на уровне пользователя или проекта.

### Marketplace Claude Code

Один раз добавьте marketplace:

```text
/plugin marketplace add ztemerbekov/a1-marketing-skills
```

Для полной установки A1 Marketing Skills:

```text
/plugin install a1-marketing-suite@a1-marketing-skills
```

В полную установку входят оба набора:

- **A1 Core:** `/a1-core:a1-grill`, `/a1-core:a1-consumer-psy` и `/a1-core:a1-marketing-context`
- **A1 Editorial:** `/a1-editorial:a1-copy-editing`, его русский алиас `/a1-editorial:a1-redaktura`, `/a1-editorial:a1-humanize` и `/a1-editorial:a1-editor-in-chief`

Чтобы установить только один набор:

```text
/plugin install a1-core@a1-marketing-skills
/plugin install a1-editorial@a1-marketing-skills
```

### Только один проект

Выполните основную команду внутри проекта и уберите `-g`:

```bash
npx skills@latest add ztemerbekov/a1-marketing-skills
```

При проектной установке выбранные версии навыков остаются с этим проектом. Полный актуальный список агентов и поведение установщика описаны в документации [`skills`](https://github.com/vercel-labs/skills).

## Обновление и удаление

Обновите шесть возможностей и русский командный алиас:

```bash
npx skills@latest update \
  a1-copy-editing \
  a1-redaktura \
  a1-editor-in-chief \
  a1-grill \
  a1-humanize \
  a1-marketing-context \
  a1-consumer-psy \
  --global \
  --yes
```

Удалите их из глобальной установки:

```bash
npx skills@latest remove \
  a1-copy-editing \
  a1-redaktura \
  a1-editor-in-chief \
  a1-grill \
  a1-humanize \
  a1-marketing-context \
  a1-consumer-psy \
  --global \
  --yes
```

Для проектных навыков выполните команду внутри проекта: используйте `--project` с `update` и уберите `--global` из `remove`.
