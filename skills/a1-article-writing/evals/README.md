# A1 Article Writing Evaluation

These manual cases protect invocation, source fidelity, and scope boundaries without requiring one golden article.

## Cases

- `article-outline-topic-001`: topic-only outline.
- `article-source-fidelity-002`: supplied facts and qualifications survive a new article.
- `article-mixed-job-003`: article plus promotional page.
- `article-existing-draft-004`: selected finished draft belongs to copy editing.
