# promo-blueprint-001 — Blueprint Preserves the Offer

- ID: `promo-blueprint-001`
- Operation: `Blueprint`
- Risk: Blueprint mode drifts into finished copy or hides missing offer facts.
- Scope Scenario: `In scope`

## User Instruction

```text
Собери blueprint промостраницы воркшопа. Для каждого блока укажи задачу читателя, сообщение, доказательство и нужный визуальный материал. Текст страницы пока не пиши.
```

## Input

```text
Однодневный очный воркшоп для руководителей отделов продаж. Участник получает рабочую тетрадь и 30-минутную консультацию после занятия. Дата, цена, место и отзывы пока не подтверждены. Главное действие — оставить заявку на лист ожидания.
```

## Must Change

- [ ] Return an ordered page blueprint.
- [ ] Give each block a reader job, message, required evidence, and useful visual or artifact when applicable.
- [ ] Surface date, price, place, and testimonials as source gaps outside page copy.

## Must Preserve

- [ ] Preserve one-day in-person format, sales leaders, workbook, 30-minute consultation, and waitlist action.
- [ ] Stay in Blueprint mode.

## Forbidden

- [ ] Do not write full page copy.
- [ ] Do not invent a price, date, venue, testimonial, scarcity, guarantee, or workshop result.
