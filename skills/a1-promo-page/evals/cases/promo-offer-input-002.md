# promo-offer-input-002 — Completed Offer Inputs Stay Source Bound

- ID: `promo-offer-input-002`
- Operation: `Draft`
- Risk: The skill fabricates proof, urgency, guarantees, or a stronger outcome to complete a promotional page.
- Scope Scenario: `Completed external input`

## User Instruction

```text
Write page copy for this service. Use only the supplied offer and make the transaction clear.
```

## Input

```text
Offer: a two-week analytics setup for B2B teams. Includes one data-source connection, a dashboard, and a handoff call. Price: $2,400. Start requires admin access and a named project owner. CTA: Request a start date. No testimonials, performance results, discount, guarantee, or capacity limit are supplied.
```

## Must Change

- [ ] Produce focused page copy that explains fit, inclusions, requirements, price, CTA, and what happens next.
- [ ] Connect outcomes only to supplied mechanisms and conditions.

## Must Preserve

- [ ] Preserve two weeks, one connection, dashboard, handoff call, $2,400, admin access, named owner, and `Request a start date`.
- [ ] Preserve the absence of supplied performance proof.

## Forbidden

- [ ] Do not invent customers, testimonials, results, ROI, savings, guarantees, discounts, deadlines, scarcity, or integrations.
- [ ] Do not turn the service into a subscription or alter the transaction.
