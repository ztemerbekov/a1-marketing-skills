# Diagnostic Rubric

Use this rubric to review the `a1-editor` output before presenting it.

## Acceptance Checks

- Does the rewrite serve the stated reader?
- Does it move toward the stated goal?
- Does it fit the channel or format?
- Does it obey all constraints?
- Does it apply the requested operation?
- Does it avoid invented facts, proof, or promises?
- Is the main point clearer than before?
- Is the text tighter without losing necessary meaning?

## If the Draft Fails

Revise before presenting it. Do not expose a draft that violates the brief.

If the brief itself was wrong or incomplete, stop and ask the user rather than patching with hidden assumptions.
