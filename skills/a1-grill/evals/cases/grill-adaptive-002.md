# grill-adaptive-002 — Adaptive Raw Idea

- ID: `grill-adaptive-002`
- Operation: `Adaptive Decision Tree`
- Risk: A raw idea receives a fixed marketing checklist instead of one proximal decision.
- Scope Scenario: `In scope`

## Setup

Install `a1-grill`. No external materials exist.

## User Instruction

```text
Запусти a1-grill. Думаю запустить подкаст для продвижения сервиса аналитики маркетплейсов. Пока это вся идея.
```

## Input

The idea has no confirmed audience, outcome, format, budget, or channel evidence.

## Must Change

- [ ] Lead with one best current recommendation that advances the root marketing decision.
- [ ] End with exactly one Russian decision question and wait.
- [ ] Treat missing information as unresolved rather than silently filling it.
- [ ] Introduce any proposed audience, outcome, or other unsupported premise with an explicit localized `Working hypothesis:` label.

## Must Preserve

- [ ] Preserve the podcast and marketplace-analytics service as the focal object.
- [ ] Keep the idea provisional and open to revision.

## Forbidden

- [ ] Do not send a multi-question intake, numbered questionnaire, or fixed lens list.
- [ ] Do not name a marketing framework merely to explain the process.
- [ ] Do not create a podcast plan, episode list, campaign, or final summary.
