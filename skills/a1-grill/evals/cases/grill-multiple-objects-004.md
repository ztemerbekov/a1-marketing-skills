# grill-multiple-objects-004 — Multiple Independent Objects

- ID: `grill-multiple-objects-004`
- Operation: `Establish Focal Object`
- Risk: Independent plans are merged into one incoherent decision tree.
- Scope Scenario: `In scope`

## Setup

Install `a1-grill`. No marketing context exists.

## User Instruction

```text
Запусти a1-grill. Хочу одновременно прожарить запуск Telegram-канала для нашего SaaS и цену отдельного авторского курса. Главная задача на следующий месяц — получить лиды для SaaS.
```

## Input

The SaaS and course are unrelated offers with separate audiences and economics.

## Must Change

- [ ] Identify the channel launch and course pricing as independent objects.
- [ ] Recommend starting with the SaaS channel because it serves the stated near-term goal.
- [ ] Ask exactly one question confirming which object to grill first.

## Must Preserve

- [ ] Preserve the next-month SaaS lead goal as the basis for the recommendation.
- [ ] Keep both objects available for separate sessions.

## Forbidden

- [ ] Do not build one tree containing both objects.
- [ ] Do not start grilling either object before the user chooses.
- [ ] Do not ask detailed questions about both plans.
