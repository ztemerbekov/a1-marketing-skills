# presentation-outline-001 — Audience-Specific Message Path

- ID: `presentation-outline-001`
- Operation: `Outline`
- Risk: The result becomes a generic topic list rather than an evidence path for the audience.
- Scope Scenario: `In scope`

## User Instruction

```text
Create a presentation outline for the COO to decide whether to approve a billing-reconciliation pilot. Do not write full slide copy yet.
```

## Input

```text
The pilot would connect Stripe and NetSuite exports for one business unit over four weeks. The supplied implementation estimate is 40 staff hours. Approval is required for data access and one project owner. No savings estimate or performance forecast is available.
```

## Must Change

- [ ] State the audience, decision, occasion, and next step.
- [ ] Return an ordered slide sequence with one takeaway, evidence need, and audience role per slide.
- [ ] Make the access, owner, duration, and effort requirements visible.

## Must Preserve

- [ ] Preserve the two systems, one business unit, four weeks, 40 staff hours, and approval requirements.
- [ ] Keep savings and performance unknown.

## Forbidden

- [ ] Do not write full slide copy, speaker notes, or a `.pptx` file.
- [ ] Do not invent ROI, savings, results, charts, or executive endorsements.
