# presentation-live-draft-002 — Live Slides and Speaker Notes

- ID: `presentation-live-draft-002`
- Operation: `Draft`
- Risk: The slides become a transcript or the notes introduce unsupported claims.
- Scope Scenario: `In scope`

## User Instruction

```text
Write slide copy and brief speaker notes for a live ten-minute customer briefing.
```

## Input

```text
Audience: current administrators. Change: exports will move from Wednesday to Tuesday starting September 3. Existing export fields and file format stay unchanged. Administrators must update any Wednesday-dependent automation before September 3. Support contact: migrations@example.com.
```

## Must Change

- [ ] Build the shortest slide sequence that explains the change, unchanged elements, required action, deadline, and support route.
- [ ] Use takeaway headlines and concise on-slide copy.
- [ ] Keep requested speaker notes separate from slide content.

## Must Preserve

- [ ] Preserve Tuesday, Wednesday, September 3, unchanged fields and format, the automation action, and the support address.

## Forbidden

- [ ] Do not add benefits, causes, downtime, migration steps, or guarantees that were not supplied.
- [ ] Do not put the full spoken script on the slides.
