# A1 Presentation Copy Evaluation

These manual cases protect audience-specific message architecture, source-supported slide claims, delivery-mode differences, and the boundary around selected decks.

## Cases

- `presentation-outline-001`: an outline assigns one takeaway and evidence need to each slide.
- `presentation-live-draft-002`: a live deck separates on-slide copy from requested speaker notes.
- `presentation-unsupported-data-003`: missing numbers remain outside finished slide copy.
- `presentation-existing-deck-004`: a selected deck is not edited.
