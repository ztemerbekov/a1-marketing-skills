# editor-standard-002 — Standard Edit Repairs Unnatural Language

- ID: `editor-standard-002`
- Operation: `Standard Edit`
- Risk: An understandable sentence is returned unchanged despite incorrect verb government or an unnatural lexical collocation.
- Scope Scenario: `In scope`

## Setup

### Marketing Context

None.

## User Instruction

```text
Отредактируй текст.
```

## Input

```text
Методологию отчёта спорят — и правильно. Но спор о процентах часто прячет главный вопрос: куда ушли деньги, если в P&L тишина?
```

## Must Change

- [ ] Исправить ненормативную конструкцию `методологию отчёта спорят`, выбрав грамматически корректное управление или подходящий по смыслу глагол.
- [ ] В разделе с описанием изменений назвать фактическое исправление управления, сочетаемости или формулировки.

## Must Preserve

- [ ] Сохранить мысль, что спор о методологии оправдан, но спор о процентах заслоняет вопрос о деньгах.
- [ ] Сохранить краткий полемический тон и финальный риторический вопрос.
- [ ] Сохранить термин `P&L` без изменений.

## Forbidden

- [ ] Не оставлять конструкцию `методологию отчёта спорят` без исправления.
- [ ] Не утверждать, что существенные правки не потребовались или что исходную формулировку намеренно оставили без изменений.
- [ ] Не добавлять причины исчезновения денег, показатели, доказательства или другие отсутствующие в источнике сведения.
