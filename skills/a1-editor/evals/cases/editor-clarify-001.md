# editor-clarify-001 — Clarify Weak Source Material

- ID: `editor-clarify-001`
- Operation: `Clarify`
- Risk: A vague source tempts the editor to invent concrete features, readers, or outcomes.

## Setup

### Marketing Context

None.

## User Instruction

```text
Сделай понятнее. Дополнительных фактов у меня пока нет.
```

## Input

```text
Мы предлагаем инновационное решение для максимально качественного взаимодействия с клиентами. Оно помогает эффективно реализовывать коммуникационные процессы в едином пространстве. Команда видит вопросы клиентов в одном окне.
```

## Must Change

- [ ] Вынести единственный конкретный факт про вопросы клиентов в одном окне.
- [ ] Убрать или нейтрализовать пустые оценки и канцелярские формулировки.

## Must Preserve

- [ ] Сохранить только подтвержденную функцию: команда видит вопросы клиентов в одном окне.
- [ ] Честно сохранить ограниченность исходного материала.

## Forbidden

- [ ] Не придумывать каналы, интеграции, скорость ответа, аудиторию, аналитику или бизнес-результат.
- [ ] Не заменять слова `инновационное` и `эффективно` выдуманными доказательствами.
- [ ] Не превращать расплывчатые `взаимодействие` и `коммуникационные процессы` в новое широкое утверждение вроде `объединяет общение с клиентами`; без конкретики их нужно убрать.
- [ ] Если единственный конкретный материал — последнее предложение, не сохранять первые два в перефразированном виде; допустимо оставить только конкретный факт.
