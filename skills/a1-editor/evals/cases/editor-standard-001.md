# editor-standard-001 — Standard Edit Preserves Voice

- ID: `editor-standard-001`
- Operation: `Standard Edit`
- Risk: Generic cleanup flattens a useful first-person voice or invents stronger marketing.

### Marketing Context

None.

## User Instruction

```text
Почисти текст. Сохрани мой живой, немного разговорный голос.
```

## Input

```text
Честно говоря, мы очень долго и продолжительно думали над тем, как не прыгать каждый день между кабинетами маркетплейсов. В итоге сделали простую штуку: сервис собирает комментарии из Ozon, Wildberries и Яндекс Маркета в один отчет. Я сам открываю его по пятницам — так хотя бы ничего не теряется в трех вкладках.
```

## Must Change

- [ ] Убрать тавтологию `долго и продолжительно` и сократить разгон перед сутью.
- [ ] Сделать связь между тремя кабинетами и единым отчетом яснее.

## Must Preserve

- [ ] Сохранить разговорное первое лицо и фразу о личном использовании по пятницам.
- [ ] Сохранить три названных маркетплейса и единый отчет без изменения фактов.

## Forbidden

- [ ] Не добавлять автоматизацию ответов, скорость обработки, метрики, CTA или обещание роста продаж.
- [ ] Не превращать текст в безличный корпоративный анонс.
