# Research-only model dossiers

These positions are available only to explain a model explicitly named by the user. They are not ordinary diagnostic candidates and do not support an intervention recommendation. Each model section owns its evidence grade and sources.

<a id="m20"></a>

## M20 — Regret Aversion

- **Role:** research-only position; explain it only when the user explicitly names it. Do not use it as an ordinary diagnosis or intervention recommendation.

### Evidence (B)

Brewer, DeFrank & Gilkey (2016), 81-study health-behavior meta-analysis, [DOI](https://doi.org/10.1037/hea0000294); Han, Quadflieg & Ludwig (2023), decision-avoidance meta-analysis, [DOI](https://doi.org/10.1371/journal.pone.0292857). Feedback, responsibility, and action/inaction make direction heterogeneous.

## M28 — Foot-in-the-Door

- **Role:** research-only position; explain it only when the user explicitly names it. Do not use it as an ordinary diagnosis or intervention recommendation.

### Evidence (B)

Beaman et al. (1983), 120 experimental groups, [DOI](https://doi.org/10.1177/0146167283092002); Burger (1999), review, [DOI](https://doi.org/10.1207/s15327957pspr0304_2). Effects are small, variable, and can reverse.

## M34 — Contrast Effect

- **Role:** research-only position; explain it only when the user explicitly names it. Do not use it as an ordinary diagnosis or intervention recommendation.

### Evidence (C)

Conway Dato-on & Dahlstrom (2003), [DOI](https://doi.org/10.1002/mar.10093); Mussweiler (2003), [DOI](https://doi.org/10.1037/0033-295X.110.3.472). Contrast and assimilation are competing operations; no unitary estimate applies.

## N06 — Ovsiankina Effect

- **Role:** research-only position; explain it only when the user explicitly names it. Do not use it as an ordinary diagnosis or intervention recommendation.

### Evidence (C)

Ghibellini & Meier (2025), 21-publication resumption synthesis, [DOI](https://doi.org/10.1057/s41599-025-05000-w). It concerns resumption, not a general interrupted-task memory advantage, and has no common counterfactual baseline.

## N09 — Cognitive Dissonance

- **Role:** research-only position; explain it only when the user explicitly names it. Do not use it as an ordinary diagnosis or intervention recommendation.

### Evidence (C)

Vaidis et al. (2024), 39-lab replication, [DOI](https://doi.org/10.1177/25152459231213375). Induced-compliance results do not validate the entire theory family.

## N10 — Effort Justification

- **Role:** research-only position; explain it only when the user explicitly names it. Do not use it as an ordinary diagnosis or intervention recommendation.

### Evidence (C)

Aronson & Mills (1959), [DOI](https://doi.org/10.1037/h0047195). A modern preregistered synthesis or replication for the narrow mechanism was not established here; progress, skill, ownership, and selection remain alternatives.

## N18 — Compromise Effect

- **Role:** research-only position; explain it only when the user explicitly names it. Do not use it as an ordinary diagnosis or intervention recommendation.

### Evidence (C)

Simonson (1989), [DOI](https://doi.org/10.1086/209205); presentation-boundary experiment, [DOI](https://doi.org/10.3758/s13423-018-1531-9). Standard, reverse, and null patterns occur across formats.

## N19 — Omission Bias

- **Role:** research-only position; explain it only when the user explicitly names it. Do not use it as an ordinary diagnosis or intervention recommendation.

### Evidence (B)

Yeung, Yay & Feldman (2021), 49-effect meta-analysis, [DOI](https://doi.org/10.1177/01461672211042315). The effect is stronger for blame/morality than choice, and publication-bias diagnostics are mixed.
