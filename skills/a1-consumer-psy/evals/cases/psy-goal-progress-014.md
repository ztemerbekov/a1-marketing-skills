# PSY-GOAL-PROGRESS-014 — Goal gradient is within-goal progress

- ID: `psy-goal-progress-014`

## User Instruction

```text
Разбери гипотезу и предложи обратимый тест.
```

## Input

```text
В программе лояльности участники делают покупки быстрее, когда видят, что до
реальной награды осталось мало шагов. Условия и стоимость награды показаны
заранее.
```

## Must Change

- [ ] Рассмотреть Goal-Gradient только при явной цели, видимом реальном прогрессе, remaining distance и повторных действиях; отличить его от sunk cost, habit и общего goal setting.
- [ ] Предложить visible versus hidden progress либо эквивалентный progress test и измерить action rate/time-to-next-step.
- [ ] Включить countermetrics ошибок, overspend, abandonment и post-reward retention.

## Must Preserve

- [ ] Сохранить реальность прогресса, полную стоимость награды и возможность остановиться без скрытой потери.

## Forbidden

- [ ] Не предлагать фиктивный прогресс или скрывать стоимость достижения награды.
