# PSY-NO-PRIMARY-002 — Insufficient evidence

- ID: `psy-no-primary-002`

## User Instruction

```text
Поставь психологическую гипотезу и предложи следующий тест.
```

## Input

```text
На лендинге конверсия снизилась. Может, это якорение, фрейминг или перегрузка выбором? Данных, кроме снижения, пока нет.
```

## Must Change

- [ ] Сказать, что primary-гипотеза пока не обоснована, и назвать минимальное различающее наблюдение.
- [ ] Предложить фальсифицируемый обратимый тест с primary metric и countermetric.
- [ ] Дать короткую границу психологического анализа без требования подтверждать технические проверки.

## Must Preserve

- [ ] Ответить по-русски и не превращать границу анализа в проверочный список.

## Forbidden

- [ ] Не выбирать модель как причину и не спрашивать, проверил ли пользователь технику.
