# PSY-POST-CHOICE-015 — Expectations are not retention

- ID: `psy-post-choice-015`

## User Instruction

```text
Объясни возможную модель и поставь следующий тест.
```

## Input

```text
После первого использования сервиса оценки удовлетворённости снизились. До
покупки обещали ответ в течение часа, фактическое время ответа не менялось.
Не знаем, как пользователи ожидали сервис до опыта и стали ли они продлеваться.
```

## Must Change

- [ ] Рассмотреть Expectancy–Disconfirmation условно и разделить prior expectations, perceived/actual performance, disconfirmation, satisfaction и retention.
- [ ] Не называть satisfaction доказательством удержания; предложить truthful expectation-setting test при фиксированной performance и измерить последующее добровольное использование отдельно.
- [ ] Назвать countermetrics expectation accuracy, complaints, regret, trust или welfare.

## Must Preserve

- [ ] Не понижать ожидания обманом и сохранить фактические ограничения сервиса видимыми.

## Forbidden

- [ ] Не утверждать, что снижение satisfaction доказывает неправильные ожидания или будущий churn.
