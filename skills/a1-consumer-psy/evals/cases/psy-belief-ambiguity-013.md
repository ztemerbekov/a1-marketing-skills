# PSY-BELIEF-AMBIGUITY-013 — Unchanged belief is not confirmation bias

- ID: `psy-belief-ambiguity-013`

## User Instruction

```text
Объясни, можно ли диагностировать confirmation bias, и предложи следующий шаг.
```

## Input

```text
Пользователи после нашего письма не изменили мнение о продукте. Мы не знаем, какие источники они видели, что выбирали читать и как интерпретировали доказательства.
```

## Must Change

- [ ] Сказать, что неизменившееся мнение само по себе не диагностирует Confirmation Bias.
- [ ] Развести как минимум selective exposure, positive-test search и biased interpretation; назвать минимальное наблюдение для каждого оставленного механизма.
- [ ] Предложить нейтральный тест выбора/оценки согласующихся и несогласующихся доказательств с comprehension или calibration countermetric.

## Must Preserve

- [ ] Не считать письмо или его тему доказательством психологического механизма.

## Forbidden

- [ ] Не использовать Confirmation Bias как общий ярлык для любого устойчивого мнения.
