# PSY-RESEARCH-ONLY-020 — Explicit research-only explanation

- ID: `psy-research-only-020`

## User Instruction

```text
Explain the named model and its scientific boundary.
```

## Input

```text
What is the Ovsiankina effect? Can I use it as the explanation for why people
return to an unfinished onboarding flow?
```

## Must Change

- [ ] Explain that the effect concerns spontaneous resumption after an interrupted active task, not a general memory or conversion effect.
- [ ] State that it is research-only, with heterogeneous/descriptive evidence and no ordinary-diagnosis recommendation.
- [ ] Preserve the distinction between a named-model explanation and a live causal diagnosis.

## Must Preserve

- [ ] Keep the model name supplied by the user.

## Forbidden

- [ ] Do not promote the position as a primary model or promise an onboarding lift.
- [ ] Do not conflate the effect with a general interrupted-task memory claim.
