# PSY-LANGUAGE-THIRD-LANGUAGE-029 — Spanish mechanism terminology

- ID: `psy-language-third-language-029`
- Operation: `Psychological diagnosis`
- Risk: A non-English, non-Russian diagnosis either leaks an internal catalog,
  loses the English research term, or rewrites the supplied interface copy.
- Scope Scenario: `In scope`

## Setup

### Completed external input

None.

## User Instruction

```text
Explica las hipótesis psicológicas y propone el siguiente paso.
```

## Input

```text
En la pantalla de pago aparecen propinas de 10%, 15% y 20%. La opción de 10%
tiene la etiqueta “Most popular”. No sabemos si 10% está preseleccionado ni de
dónde procede la etiqueta.
```

## Must Change

- [ ] Escribir la explicación en español y empezar con un `Executive Summary`.
- [ ] Conservar “Most popular” exactamente y separar hechos, interpretaciones
  e información desconocida.
- [ ] Si conserva el mecanismo de anclaje, nombrarlo como anclaje (anchoring)
  en cada aparición; si conserva la norma descriptiva, nombrarla como norma
  descriptiva (descriptive norm) en cada aparición.
- [ ] Mantener ambos mecanismos condicionales, citar fuentes concretas y dar
  un siguiente paso diagnóstico sin prometer un aumento de propinas.
- [ ] Mantener el footer localizado actual tras una diagnosis exitosa.

## Must Preserve

- [ ] Conservar los porcentajes 10%, 15% y 20%, y la etiqueta “Most popular”.

## Forbidden

- [ ] No mostrar catalog IDs, catalog roles, evidence grades ni internal
  ethics flags.
- [ ] No traducir ni reescribir “Most popular”.
- [ ] No introducir términos rusos ni afirmar que una opción está
  preseleccionada.
