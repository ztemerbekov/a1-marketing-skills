# PSY-IF-THEN-011 — Implementation intentions need a cue and a goal

- ID: `psy-if-then-011`

## User Instruction

```text
Разбери психологическую гипотезу и предложи безопасный тест.
```

## Input

```text
Хотим, чтобы больше пользователей завершали добровольную настройку профиля.
Предлагаем им план: «Когда открою приложение утром, сразу заполню профиль».
```

## Must Change

- [ ] Рассмотреть Implementation Intentions только при наличии значимой добровольной цели и выполнимой связки «если сигнал, то действие»; отличить план от общего напоминания или расписания.
- [ ] Предложить сравнение с равно-контактным reminder/goal-only вариантом и измерить целевое действие на последующем периоде.
- [ ] Назвать countermetrics: burden, ошибочные действия, нежелательный автоматизм или возможность отключить план.

## Must Preserve

- [ ] Сохранить добровольность цели и возможность удалить или отключить план.

## Forbidden

- [ ] Не обещать эффект и не называть любую фразу о намерении планом «если — то».
