# PSY-SECONDARY-010 — Every retained hypothesis is instrumented

- ID: `psy-secondary-010`

## User Instruction

```text
Разбери психологические гипотезы и предложи следующий тест.
```

## Input

```text
После изменения ценовой страницы упал старт оплаты. В новом варианте первой показана честная годовая цена, а рядом с тремя планами добавлены три коротких сценария выбора. У нас есть только общая конверсия, без долей выбора планов и без данных о понимании.
```

## Must Change

- [ ] Не считать последовательность и совпадение слов доказательством; можно оставить no primary или не более двух действительно разных рабочих гипотез.
- [ ] Для каждой сохранённой гипотезы показать признаки, недостающие различающие данные, evidence-context limit, prediction, minimal test, primary metric, countermetric, backfire и decision rule.
- [ ] Если один тест обслуживает несколько гипотез, объяснить, как его результат их различит.

## Must Preserve

- [ ] Сохранить факты о честной годовой цене, сценариях выбора и неполных данных.

## Forbidden

- [ ] Не называть anchoring или framing причиной только по порядку либо словам в описании; не давать неинструментированную secondary-гипотезу.
