# PSY-LANGUAGE-009 — Mixed language and copy preservation

## User Instruction

```text
Объясни возможный механизм и предложи тест.
```

## Input

```text
На checkout добавили текст ‘Most popular’. Объясни, может ли это быть framing, но сам текст не переводи.
```

## Must Change

- [ ] Начать с `Executive Summary`, объяснить на русском, сохранить `Most
  popular` точно, рассмотреть фрейминг (framing) условно и предложить
  правдивый тест с comprehension или trust countermetric.
- [ ] Для любого оставленного механизма использовать русское название с
  английским термином в скобках и не показывать internal catalog notation.

## Must Preserve

- [ ] Сохранить quoted UI text exactly.

## Forbidden

- [ ] Не переводить/переписывать UI text и не называть label доказательством framing effect.
