# editor-information-style-003 — Information Style Preserves Technical Markdown

- ID: `editor-information-style-003`
- Operation: `Information Style`
- Risk: A deep rewrite corrupts technical Markdown or fills missing explanations from model knowledge.

## Setup

### Marketing Context

None.

## User Instruction

```text
Перепиши в информационном стиле и улучши Markdown. Не меняй ссылку, формулу, кодовый блок и ограничение. Не добавляй объяснений из своих знаний.
```

## Input

````markdown
# Как работают большие языковые модели (LLM)

Наткнулся на потрясающее [видео](https://www.youtube.com/watch?v=wjZofJX0v4M), где устройство нейросетей объясняется буквально «на пальцах».

Вы узнаете, что такое «веса» языковых моделей и как работает векторная арифметика смыслов. В видео приведено семантическое уравнение `E(Суши) + E(Германия) − E(Япония) = E(Колбаски)`.

Пример из материала:

```text
E(Суши) + E(Германия) − E(Япония) = E(Колбаски)
```

> Видео длится 30 минут.

Главная мысль: под капотом LLM нет магии и «искры разума». Это статистическая машина, которая математически высчитывает наиболее вероятное продолжение текста.
````

## Must Change

- [ ] Убрать пустое восхищение и быстрее вывести пользу уже имеющегося материала.
- [ ] Организовать существующий материал в валидный, сканируемый Markdown, сохранив заголовок, code fence и blockquote корректными структурами.
- [ ] Оставить главную мысль легко заметной.

## Must Preserve

- [ ] Сохранить link target `https://www.youtube.com/watch?v=wjZofJX0v4M` посимвольно.
- [ ] Сохранить обе записи семантического уравнения, backticks, code fence, `30 минут` и все технические термины без повреждений.

## Forbidden

- [ ] Не придумывать отсутствующее определение весов модели, объяснение уравнения, новые факты, будущую пользу или выводы.
- [ ] Не повреждать Markdown-ссылку, inline code, code fence или blockquote и не усиливать утверждения до более широких категоричных claims.
