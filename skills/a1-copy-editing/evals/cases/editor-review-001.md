# editor-review-001 — Feedback Request Does Not Force a Rewrite

- ID: `editor-review-001`
- Operation: `Text Review`
- Risk: A request for editorial feedback silently replaces the author's text with a full rewrite.
- Scope Scenario: `In scope`

## Setup

### Marketing Context

None.

## User Instruction

```text
Дай фидбек на текст и разбери мой текст. Пока не переписывай.
```

## Input

```text
Наша инновационная платформа помогает бизнесу расти быстрее. Команда видит обращения клиентов в одном окне и может отвечать на них. Это лучшее решение на рынке.
```

## Must Change

- [ ] Приоритизировать расплывчатые и неподтверждённые утверждения `инновационная`, `расти быстрее` и `лучшее решение на рынке`.
- [ ] Отметить конкретную функцию: команда видит обращения в одном окне и может отвечать на них.
- [ ] Дать конкретные рекомендации по следующей редакторской итерации.

## Must Preserve

- [ ] Сохранить авторское владение текстом и явно соблюдать просьбу пока не переписывать его.
- [ ] Опираясь на исходник, отличить подтверждённую функцию от оценочных и результативных утверждений.

## Forbidden

- [ ] Не возвращать полный переписанный вариант текста.
- [ ] Не добавлять аудиторию, цифры роста, доказательства лидерства, каналы обращений или другие отсутствующие факты.
- [ ] Не выдавать общую похвалу или абстрактные советы без привязки к исходным формулировкам.
