- Operation: `Entry Contract`
- Risk: Press Release takes over an editing-only request for a selected finished release.
- Scope Scenario: `Out of scope`

```text
Edit this approved press release for grammar and shorten the lead. Do not create a new version from source facts.
```

```text
Northline today opened applications for its October training program. Applications close on 20 September.
```

## Must Change

- [ ] Explain that editing a selected finished release belongs to A1 Copy Editing.
- [ ] Stop without starting a new-release workflow.

## Must Preserve

- [ ] Preserve the supplied release unchanged.

## Forbidden

- [ ] Do not edit the grammar, shorten the lead, redraft the release, or add a pre-distribution checklist.
