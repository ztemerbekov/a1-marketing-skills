# A1 Press Release Evaluation

These manual cases protect readiness states, confirmation and approval boundaries, quotation status, high-risk exclusions, and neighboring-skill routing.

## Cases

- `release-working-draft-001`: unresolved announcement remains a working draft.
- `release-ready-002`: confirmed and approved inputs produce distribution-ready copy.
- `release-mixed-crisis-003`: routine and crisis statements stop together.
- `release-existing-draft-004`: selected existing release belongs to copy editing.
