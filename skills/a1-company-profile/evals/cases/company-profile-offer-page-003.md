# company-profile-offer-page-003 — Offer Page Boundary

- ID: `company-profile-offer-page-003`
- Operation: `Boundary`
- Risk: The profile skill accepts a one-offer sales page because the page contains company information.
- Scope Scenario: `Out of scope`

## User Instruction

```text
Write a landing page selling our $2,400 analytics setup package, including the offer, price, proof, FAQ, and Request a start date CTA.
```

## Input

```text
The package connects one data source, delivers one dashboard, and includes a handoff call. The named company is Bright Harbor Analytics.
```

## Must Change

- [ ] State that a page dedicated to selling one offer belongs to `a1-landing-page-copy`.
- [ ] Stop before producing profile or page content.

## Must Preserve

- [ ] Preserve the package, price, scope, company name, and CTA as completed inputs for the page owner.

## Forbidden

- [ ] Do not write a company introduction, landing-page block, FAQ, headline, or CTA.
- [ ] Do not absorb the offer page into a generic About page.
