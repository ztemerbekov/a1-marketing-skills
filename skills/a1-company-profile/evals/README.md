# A1 Company Profile Evaluation

These manual cases protect factual company description, behavior-backed mission and values, and the boundaries around offer pages and selected profiles.

## Cases

- `company-profile-outline-001`: a new About-page outline answers reader questions from supplied facts.
- `company-profile-values-002`: confirmed values are expressed through observable practices.
- `company-profile-offer-page-003`: an offer-specific sales page routes elsewhere.
- `company-profile-existing-draft-004`: a selected company profile is not edited.
