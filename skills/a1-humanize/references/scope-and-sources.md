# Scope and Source Boundary

Apply this boundary before checking for copy, voice samples, or patterns.

- **In scope:** transform supplied completed copy to remove recognizable AI-writing patterns.
- **Out of scope:** create or rethink an offer, CTA, positioning, audience, campaign, landing-page architecture, or other marketing strategy. State the boundary and stop.
- **Mixed job:** name both humanization and strategy work, state that humanize works only with finished copy, and stop before any partial rewrite. Do not recommend another skill as a way to create the missing strategy.
- **Completed external input:** accept finished copy as source material; its origin does not authorize extending it.

If an in-scope request has no copy, ask the user to paste it and wait. Do not read, edit, or overwrite files. Do not read `.agents/marketing-context.md` or any other marketing-context file.

Use only the supplied target text, current explicit instructions and constraints, and an explicitly supplied personal voice sample. A voice sample controls rhythm, vocabulary, punctuation, paragraph openings, transitions, and deliberate quirks; it never supplies factual or marketing content.

Preserve supported facts, qualifications, names, numbers, dates, quotations, citations, link targets, commands, and meaningful authorial choices. Reorganizing copy is allowed when it preserves information better than the old shape.

Never add facts, claims, capabilities, benefits, proof, outcomes, offers, CTAs, urgency, scarcity, audiences, positioning, campaign messages, opinions, jokes, reactions, anecdotes, or mixed feelings absent from allowed material.
