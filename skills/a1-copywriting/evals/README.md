# A1 Copywriting Evaluation

These manual cases protect hybrid route-or-write behavior, format ownership, mixed-job handling, and the boundary around selected existing drafts.

## Cases

- `copywriting-route-page-001`: an explicit Copywriting request reaches Landing Page Copy.
- `copywriting-route-cold-email-002`: an unlabelled first-contact message reaches Cold Email.
- `copywriting-existing-draft-003`: a selected draft stays outside Copywriting.
- `copywriting-mixed-formats-004`: different owners are identified before any artifact is produced.
- `copywriting-route-business-message-005`: an existing-contact workplace message reaches Business Message.
- `copywriting-direct-ordinary-copy-006`: an ordinary marketing-copy request with no listed A1 owner is written directly.
- `copywriting-specialist-boundary-007`: a specialist or high-stakes format remains outside generic fallback.
- `copywriting-mixed-route-direct-008`: routed and direct-fallback deliverables are classified before the user chooses one.
