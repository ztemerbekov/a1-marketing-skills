# A1 Decision Memo Evaluation

These manual cases protect decision, response, and awareness jobs; specialist-input boundaries; and mixed-job routing without requiring one golden memo.

## Cases

- `memo-awareness-001`: awareness-only status memo.
- `memo-specialist-input-002`: completed legal analysis remains attributed input.
- `memo-mixed-strategy-003`: memo plus unsupported strategy choice.
- `memo-existing-draft-004`: selected finished memo belongs to copy editing.
