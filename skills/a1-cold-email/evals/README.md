# A1 Cold Email Evaluation

These manual cases protect recipient-specific relevance, honest uncertainty, low-friction next steps, and the boundaries around sequences and selected drafts.

## Cases

- `cold-email-relevance-001`: one supported connection produces a concise first-contact email.
- `cold-email-uncertain-fit-002`: incomplete fit remains explicitly uncertain.
- `cold-email-sequence-003`: a campaign request stops before partial drafting.
- `cold-email-existing-draft-004`: a selected email is not edited.
